# Contributing

Use an issue to describe a concrete false positive, missed pattern or lesson improvement. Include synthetic minimal code, expected behavior and the affected version. Do not post secrets or private source.

Run `npm test`, `python3 -m unittest discover -s test -p 'test_*.py'`, `npm run demo`, `npm run build` and `npm run scan`. Add a risky and a corrected case for rule changes. Explain blind spots and confidence. No accuracy, certification or zero-vulnerability claims without independent evidence. Keep PT-BR and English study content aligned and browser rendering text-only.

Security reports belong in the private channel in SECURITY.md. External testing must have authorization. PRs should stay focused and document sources and licenses.
